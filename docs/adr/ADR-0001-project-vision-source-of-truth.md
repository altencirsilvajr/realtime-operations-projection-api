# ADR-0001: Project vision is the source of truth

- Status: Accepted
- Date: 2026-07-11

## Context

Este é um laboratório de portfólio. Sem uma fronteira explícita, conveniências de demonstração poderiam virar funcionalidades de produto.

## Decision

`PROJECT_VISION.md` define propósito, fluxo obrigatório e critérios de sucesso. Mudanças que o contradigam exigem ADR nova ou a atualização explícita da visão.

## Consequences

O projeto favorece clareza arquitetural e rastreabilidade em vez de amplitude funcional.
